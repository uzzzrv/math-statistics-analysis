Учебный проект по математической статистике: анализ статистических распределений. 

Цель: сгенерировать выборки различных распределений, рассчитать их числовые характеристики, визуализировать и сравнить с теоретическими значениями.

Распределения:
- Биномиальное (n = 8, p = 0.552)
- Отрицательное биномиальное (r = 6, p = 0.552)
- Показательное (λ = 1.078)

Что сделано:
- Сгенерированы выборки объёмом N = 200
- Построены статистические ряды и эмпирические функции распределения
- Рассчитаны: среднее, дисперсия, СКО, мода, медиана, асимметрия, эксцесс
- Построены полигоны частот и гистограмма с плотностью
- Результаты выведены в таблицах 
- Проведено сравнение выборочных характеристик с теоретическими

Стек:
- Python 3.12
- NumPy — генерация выборок
- SciPy — теоретические распределения
- Matplotlib — визуализация
- Tabulate — таблицы в консоль
