Учебный проект по математической статистике: генерация выборок, расчёт характеристик, визуализация, проверка гипотез.

Часть 1. Анализ статистических распределений

Цель: сгенерировать выборки различных распределений, рассчитать их числовые характеристики, визуализировать и сравнить с теоретическими значениями.

Распределения:
- Биномиальное (n = 8, p = 0.552)
- Отрицательное биномиальное (r = 6, p = 0.552)
- Показательное (λ = 1.078)

Что сделано:
- Сгенерированы выборки объёмом N = 200
- Построены статистические ряды и эмпирические функции распределения
- Рассчитаны: среднее, дисперсия, СКО, мода, медиана, асимметрия, эксцесс
- Построены полигоны частот и гистограмма с плотностью
- Результаты выведены в таблицах
- Проведено сравнение выборочных характеристик с теоретическими



Часть 2. Проверка статистических гипотез

Цель: проверить гипотезы о соответствии выборок теоретическим распределениям.

Что сделано:
- Критерий χ²: проверка гипотезы о нормальном распределении
  - Построена гистограмма с наложенной плотностью
  - Вычислено χ² = 2.82250 (при критическом 12.37462) → гипотеза принята
- Критерий Колмогорова: проверка гипотезы о показательном распределении
  - Построена эмпирическая функция распределения
  - Вычислено DN√N = 0.56565 (при критическом 1.449086) → гипотеза принята

Стек: Python (Numpy, SciPy, Matplotlib, Tabulate)
